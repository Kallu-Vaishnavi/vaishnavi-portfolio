# Kallu Vaishnavi — Personal Portfolio

A personal portfolio website showcasing the profile, technical skills, projects, professional journey, certifications, and contact information of **Kallu Vaishnavi**, a Java Full Stack Developer.

## 🌐 Live Portfolio

Coming soon — the website will be hosted on Vercel.

## 👩‍💻 About

This portfolio presents Vaishnavi's developer profile, technical interests, projects, and professional journey in a clean, modern, and interactive interface.

## ✨ Features

- Modern, responsive portfolio design
- Personal introduction and profile section
- Technical skills and expertise
- Project showcase
- Education and professional journey
- Certifications section
- Contact information
- Interactive animations and transitions
- Links to learning resources and coding practice
- Downloadable resume

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP and ScrollTrigger
- Lenis Smooth Scroll

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Kallu-Vaishnavi/vaishnavi-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd vaishnavi-portfolio
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code.
